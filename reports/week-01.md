## 4. Khó khăn và blocker

### Vấn đề

- Ban đầu máy chưa cài Node.js nên không sử dụng được `npm` và `npx`.
- PowerShell chặn việc thực thi `npm.ps1`.
- Chưa quen cấu trúc App Router của Next.js.
- Chưa quen cách sử dụng TypeScript và Tailwind CSS.

### Cách đã thử

- Cài đặt Node.js.
- Kiểm tra Node.js và npm bằng terminal.
- Xử lý vấn đề PowerShell Execution Policy.
- Chạy thử project bằng `npm run dev`.
- Đọc tài liệu và thử chỉnh sửa `page.tsx`.
- Chia chức năng thành từng phần nhỏ để thực hiện.

### Hỗ trợ cần thiết

- Tiếp tục tìm hiểu Next.js Server Component và Server Actions.
- Tìm hiểu Prisma ORM và PostgreSQL để triển khai database trong tuần tiếp theo.
